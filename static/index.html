Retrieval supplies the field semantics that make the generated query right — and the pipeline refuses, abstains, or flags its own uncertainty rather than guessing.

What's under the hood

Routing

  • Six routes, chosen by rules — instant and explainable
  • Three of them answer with no model at all
  • Every decision reports the pattern that fired

Retrieval

  • Hybrid: BM25 (sparse) + bge-m3 (dense)
  • Merged by Reciprocal Rank Fusion, k=60
  • BM25 finds literal codes and figures embeddings lose
  • Separate corpora for SQL grounding and definitions

Numbers

  • DuckDB over 100% of rows — 1.67M records, no sampling
  • Read-only, external file access disabled, table allowlist
  • Generated SQL screened, bounded, and shown to you
  • crime_only drops 49% of "crime" rows — not crimes

Honesty

  • Person-directed lookups refused before retrieval runs
  • Value judgements return metrics and decline the verdict
  • Abstains when the data provably does not record it
  • Confidence stated in the text, not hidden in a field

Models — all local

  • qwen2.5-coder:7b writes the SQL
  • granite3.1-dense:8b writes grounded prose
  • bge-m3 embeds (multilingual, 1024-dim)
  • No cloud APIs, no keys
