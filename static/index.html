What's under the hood

Routing

  • Six routes, chosen by rules — no model call, so it is instant and explainable
  • aggregate · scorecard · definition · lookup · value judgment · unanswerable
  • Every decision reports the pattern that fired

Retrieval

  • Hybrid: BM25 (sparse) + bge-m3 embeddings (dense)
  • Merged by Reciprocal Rank Fusion, k=60
  • BM25 finds literal codes and figures that embeddings lose
  • Two corpora: view-aware facts ground SQL; data dictionaries answer definitions

Numbers

  • DuckDB over 100% of rows — 1.5M+ records, no sampling
  • Read-only, external file access disabled, table allowlist
  • Generated SQL is screened, bounded, and printed with the answer
  • crime_only excludes non-crime police activity — 49% of "crime" rows

Honesty

  • Person-directed lookups refused before retrieval runs
  • Value judgements return metrics and decline the verdict
  • Abstains when the data provably does not record it
  • Explicit confidence, stated in the text — not hidden in a field

Models — all local

  • qwen2.5-coder:7b writes the SQL
  • granite3.1-dense:8b writes grounded prose
  • bge-m3 embeds (multilingual, 1024-dim)
  • No cloud APIs, no keys
